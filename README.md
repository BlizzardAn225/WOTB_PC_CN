# WoTB Steam客户端登录国服 - 公开版

> 坦克世界闪击战 Steam(PC) 直营服客户端的国服登录辅助工具。
> 原理：在你自己的电脑上完成本地登录代理，把**你自己**在模拟器里登录国服产生的登录凭证，
> 用于你自己的 Steam 版客户端登录国服。不涉及任何他人账号。

## 它做什么

1. **本地登录代理**：在本机 `127.0.0.1:80 / 127.0.0.1:443` 启动代理（**仅监听回环地址，局域网内其它设备无法连接**），
   接管游戏配置/登录域名（见下方域名清单），将亚服配置改写为国服配置，并把登录 API 转发到真实国服服务器。
2. **收割你自己的登录凭证**：你在安卓模拟器里登录国服客户端时（网易版或益玩版均可），
   登录 API 响应中的**你自己的**凭证会被保存到本机 `state\` 目录（明文，至少 10 小时有效）。
3. **拉起并注入 PC 客户端**：通过内置 frida-inject 向 Steam 版 wotblitz.exe 注入脚本，
4. **自动收割版本号**：自动从模拟器客户端的引擎日志读取当前版本号并自动对齐格式（任一渠道客户端均可）。

## 它不做什么

- 不收集、不上传任何数据 —— 没有遥测、没有统计、没有外部服务器。
- 不读取你的账号密码 —— 凭证来自官方 OAuth 登录流程的响应，工具只做本地保存与回注。
- 不修改 Windows 证书信任库 —— 自签证书只通过 adb 安装进**模拟器**（用于本地代理解密）。
- 不修改游戏账号数据 —— 只影响登录环节。

## 环境要求与使用

**环境**：Windows 10/11 x64 · Steam 版《坦克世界闪击战》 · MuMu6 模拟器（安卓15、开启 Root）（注意，非 MUMU6 模拟器恕不提供技术支持）

**首次使用**：
1. 使用前，先在 KernelSU 中，为 `shell` 授予超级用户权限，然后把模拟器安卓设备-设备设置-开发者选项-磁盘共享，改为可写系统盘，重启模拟器安卓设备；
2. 运行本程序，选择你的《坦克世界闪击战》客户端，或者输入包名，程序拉起模拟器中安卓客户端后，点一次「战斗」按钮，进入车库时即可关闭模拟器客户端；
3. 随后会自动拉起Steam PC客户端，点「立即畅玩」，理论上国家随便选，然后就会进入登录流程（如果没有自动拉起PC客户端，手动启动也可以）。

**日常使用**：
- 启动程序（自动开启本地代理），程序会自动拉起PC端，PC端根据登录缓存自动登录。
1. 若PC端登录失败，在命令行窗口输入Y并回车，将进入修复流程；
2. 模拟器内打开任一国服客户端并登录（停在「战斗」前点一下即可）；
3. 程序提示就绪后自动拉起 PC 客户端，在登录页点「立即畅玩」。

## 重置脚本

本程序涉及对电脑hosts、模拟器hosts的持久化劫持、对wotblitz.exe的修改，故提供重置脚本以备使用。你需要将bat脚本、ps1脚本**全部下载并放在同一目录**，**运行bat脚本**而不是ps1脚本。

- 如果你想要在**不启动本程序**的情况下，启动模拟器中的《坦克世界闪击战》客户端，则应回滚模拟器hosts；
- 如果你想要进入直营服PC客户端，则应回滚电脑hosts、删除WoTB PC端登录缓存、恢复wotblitz.exe.bak后，再启动游戏。

脚本中提供了相应的功能。

## 🔍 自行审计

本程序**不公开源码**，但它的行为全部可被外部工具验证。以下审计方法任何人都可以执行：

### 1. 流量审计

程序自身只会连接以下域名（除此之外无任何外联）：

| 域名 | 用途 |
|---|---|
| `dns.alidns.com` | DoH 域名解析（唯一的非游戏域名连接） |
| `cn1.plt.ms1shanghai.cn` | 国服登录/账号 API（转发至真实服务器） |
| `dl-wotblitz-gc.wargaming.net` | 游戏配置/CDN |
| `cdn.static.wotb.app` | 游戏配置/CDN |
| `ma67.gdl.netease.com` | 网易资源 CDN |

验证方法：
- **netstat**：运行程序后 `netstat -ano | findstr <PID>`，检查该进程的全部 TCP 连接是否都在上表内；
- **Wireshark / Fiddler**：抓包过滤上表域名，检查请求内容是否只是游戏配置与登录 API；
- **边界验证**：代理只监听 `127.0.0.1`（`netstat -ano | findstr ":443"` 可见）——即便不做任何防火墙配置，
  局域网/公网方向都无法连入。

### 2. 行为审计

- **Process Monitor / Process Explorer**：观察进程树、文件与注册表访问——
  程序只在自身目录（`state\ logs\ certs\`）、系统临时目录（frida-inject 解压）与模拟器 adb 内活动；
- **虚拟机/沙箱**：建议首次在虚拟机中运行观察；
- **hosts 修改**：程序启动时自动把上表游戏域名写入 Windows hosts 指向 `127.0.0.1`，
  每条均带 `# wotb-cn-launcher` 标记，`WoTB_CN_pub.exe restore-hosts` 可一键还原——
  写了什么、删了什么，打开 hosts 文件即可逐行核对；模拟器内的 hosts/证书由程序经 adb 自动配置。
> **杀毒软件误报**：程序内置 frida-inject 并会向游戏进程注入内存补丁，
  被杀软启发式引擎报毒（HackTool / Inject 等名称）属**预期行为**。
  是否相信本程序，请以上述流量/行为审计结果为准，而不是以杀软 verdict 为准。

## FAQ

**Q：没法自动拉起模拟器，或者adb连接失败怎么办？**

由于MUMU模拟器adb端口分配按设备编号来，从 `16384` 端口递增，本程序硬编码了 `16384` 和 `5555` 端口，以及 `16384 + 32N` 端口递增扫描机制。
1. 检查 `MuMuPlayer\vms\`，或者你的MUMU模拟器安装目录下的 `vms` 目录，确定你的《坦克世界闪击战》安装在哪个安卓设备。例如，你的目录下有 `MuMuPlayer-15.0-0`、`MuMuPlayer-15.0-1`、`MuMuPlayer-12.0-2`，且你的《坦克世界闪击战》客户端安装在 `MuMuPlayer-15.0-1` 中；
2. 先将 `MuMuPlayer-15.0-0` 最后的 `0` 设置为其他数字，**为保证稳定收割**，需要将 `MuMuPlayer-15.0-1` 末尾的 `1` 设置为 `0`，该设备的adb端口才是16384端口；
3. 结束MUMU模拟器的进程（桌面右下角角标退出）后再打开，修改即成功，本程序收割时不要启动多个模拟器安卓设备实例。接下来就可以被本程序连接了。
> 如果提示缺 NUL，那是系统本身的问题，用户需要**自行寻求**启用 `null.sys` 的解决方案。

**Q: 需要一直开着模拟器吗？**

不需要。登录凭证收割完成后至少 10 小时内，PC 可直接登录。脚本中的 `| 已缓存 xx 小时 | 剩余 xx 小时 | 有效` 仅供参考，根据先前的经验，此有效期很长，至少有三天，只不过本次制作，做了到期重新收割机制，所以不得不超过10小时就重新收割一次。

**Q: 会封号吗？**

**Q: 为什么不开源？**

**Q: PC端登录国服后弹“无法连接到商店，请重启游戏”怎么办？**

不用管，点取消就行。单纯没做公告、国服专属活动、国服商店的桥接，因为登进了国服并且战斗、聊天、玩训练房是一步到头，就懒得做这三样的桥接了，也没必要做，去模拟器/手机端看一眼就行，而且战斗的数据会正常计入活动的。

**Q: 显示下载配置文件失败、进入车库后下载时显示未连接服务器怎么办？**

换个网络或者挂个游戏加速器，这两步连的是WG服务器，会被网络波动影响，下完了关掉加速器就不影响正常在国服玩。

**Q: 为什么开训练房显示参数错误？**

得填房间说明，国服是让玩家选的，比如战车/地图调试、军团招募与训练、竞赛、已定制等等，用Steam端登入国服，没有这些可选的就得自己填，只能填国服让选的几样。
